# 设计文档 · 总览与设计理念

> 本目录是项目的**系统设计文档（分模块）**。每篇聚焦一个模块，统一包含：模块职责、
> 设计理念（为什么这样设计）、核心抽象、关键流程、协作关系与扩展点。

## 1. 系统定位

本项目面向赛题"多智能体协作的低开销通信、状态传递与共享记忆机制"，实现的是多智能体
协作的**系统层机制原型**，而非又一个工作流编排框架。我们关注的核心问题是：

> 当多个智能体协作完成复杂任务时，如何在**系统层**降低协作开销、避免重复计算、
> 让经验可被复用——而不是把所有信息都塞进自然语言文本里反复编解码与透传。

围绕这一问题，系统提供三大支柱机制，并用一套可复现的实验框架量化其收益：

1. **低开销结构化通信**：以强类型消息契约 + 引用（而非全文搬运）承载协作信息。
2. **非文本中间状态传递**：在 Agent 间直接交换 embedding / 紧凑状态向量 / 计划 DAG，
   且接收方**真实消费**这些状态参与决策，而非编码回文本。
3. **共享记忆复用**：将中间结论/策略沉淀为统一记忆单元，支持跨任务的关键词/标签/
   语义检索与复用，并对复用效果做正/负反馈闭环。

## 2. 设计理念总纲

整套系统贯穿以下设计哲学，后续每个模块文档都会回扣到这些原则：

### 理念一：引用优于搬运（Reference over Transfer）
长内容（事实表、代码、证据、向量）只存一次，消息中只携带**内容寻址的引用**
（`artifact://`、`state://`、`memory://`、`vector://`）+ 摘要 + 访问元数据。
这是"低开销通信"的根基——通信开销与内容体量解耦。

### 理念二：结构高于辞藻（Structure over Prose）
Agent 间传递的是**强类型结构化消息**（动作类型、能力、参数、引用、状态、置信度…），
而非自然语言长文本。语义由字段承载、由 schema 约束、可被机器校验与路由。文本模式
仅作为**对照基线**存在，用于公平量化结构化协议的收益。

### 理念三：状态直传且必被消费（State Passed AND Consumed）
非文本状态不是"传了就算"。我们要求接收方**真实使用**它参与决策（如检索 Agent 用
plan embedding 做语义排序、用 DAG 还原子任务），否则就是无意义的指标灌水。这是
"状态传递创新"区别于噱头的关键。

### 理念四：经验可复用且带反馈闭环（Reusable Memory with Feedback）
记忆不仅能写入和检索，还要区分"被检索到 / 被使用 / 有效 / 有害（负迁移）"四个层级，
并据此动态调整记忆质量分，让错误经验逐步被淘汰。复用必须是**有质量保障**的复用。

### 理念五：可降级的系统增强（Graceful Degradation）
共享内存、cgroup、namespace、Podman 等系统层能力按可用性**自动探测与降级**：
目标环境（openEuler）能用就启用更强隔离/零拷贝传输，环境缺失则平滑回退到可移植实现，
保证"到处能跑"与"能更强则更强"兼得。

### 理念六：可复现与诚实度量（Reproducible & Honest Metrics）
mock-first（确定性 LLM/embedding，无需密钥即可复现），固定随机种子，多次重复，
结果带时间戳落盘不覆盖。**绝不以牺牲成功率换取 token 节省**——所有节省类指标
必须与成功率同时报告。

### 理念七：分层不倒置（Clean Layering）
基础层（异常、Provider、协议）不依赖高层（运行时装配、Agent）。这条原则直接体现在
异常类被放在顶层 `agent_runtime.errors`，避免底层模块反向触发高层包初始化而形成
循环依赖。

## 5. 一次任务的端到端数据流（速览）

```
Task ──> Orchestrator
  │  握手+能力发现，解析流水线阶段到具体 Agent
  ├─> Planner   : 产出 plan(operation, operands, defect)
  │      └─(结构化模式)─> 计划编码为 state://（DAG+embedding+向量），事实表存 artifact://
  ├─> Retriever : 消费 plan embedding 做语义排序 → 检索 evidence；查共享记忆复用经验
  ├─> Executor  : codefix→应用策略并在沙箱验证 / 算术→沙箱执行；命中记忆则跳过重复计算
  └─> Reviewer  : 自动验收 → 写回记忆 + 复用效果反馈(Effective/Harmful)
  收尾：释放 per-task 的 state_exchange（共享内存句柄），记忆库跨任务保留
```
